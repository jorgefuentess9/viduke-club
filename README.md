# ViDuke Club - Videoclub Web

Proyecto de desarrollo web creado para el módulo de **Lenguajes de Marcas y Sistemas de Gestión de Información** (3.er Trimestre - DAM).

## Descripción
ViDuke Club es una plataforma web orientada al alquiler de películas y gestión de contenido multimedia con temática del mascot de Java (Duke). Combina maquetación web estructurada, diseño adaptable (responsive) y dinamismo con JavaScript.

## Tecnologías utilizadas
* **HTML5:** Estructura semántica de las páginas web.
* **CSS3:** Estilos personalizados, diseño responsive y disposición de elementos.
* **JavaScript (Vanilla):** Lógica de interacción y manipulación del DOM.

## Características
* Interfaz intuitiva y adaptada a diferentes dispositivos.
* Navegación entre la portada, catálogo de películas y área de miembros/alquiler.
* Estructura limpia siguiendo buenas prácticas de desarrollo web.
